WHAT WAS THE PROBLEM?
================================================================================
When a nominee approved consent in the consent portal, the system tried to 
redirect to the dashboard but it wasn't working because:

1. The dashboard was NOT checking for the "auto_extract=true" parameter
2. The dashboard was NOT loading the case_id from the URL
3. The dashboard was NOT navigating to the Extraction tab automatically

WHAT DID I FIX?
================================================================================
I made 2 key changes to modules/dashboard.py:

CHANGE 1: Added URL Parameter Handling (Lines 1876-1885)
---------
The main() function now checks for:
  - case_id parameter in URL
  - auto_extract parameter in URL

When these are detected:
  - Sets session_state['case_id'] to the case_id from URL
  - Sets session_state['auto_extract_triggered'] = True
  - Sets session_state['nav'] = 'Extraction' to navigate to extraction tab

CHANGE 2: Added Tab Navigation Logic (Lines 512-552)
---------
The render_dashboard_home() function now:
  - Checks the nav state in session_state
  - Automatically selects the correct tab (Extraction tab if nav='Extraction')
  - Shows a message when auto-extract is triggered
  - Calls render_extraction_tab() with the case_id

HOW THE FLOW WORKS NOW
================================================================================
1. Nominee opens approval link in consent portal
2. Nominee clicks "Approve" button
3. Approval is saved to file
4. Consent portal redirects to:
   http://localhost:8502?case_id=CASE_001&auto_extract=true

5. Dashboard receives the redirect and:
   - Extracts case_id from URL → CASE_001
   - Extracts auto_extract from URL → true
   - Sets session_state['case_id'] = 'CASE_001'
   - Sets session_state['auto_extract_triggered'] = True
   - Sets session_state['nav'] = 'Extraction'

6. Dashboard renders with Extraction tab selected
7. User sees message: "🔄 Auto-extraction triggered from approval!"
8. Extraction tab is ready for the user to start extraction

TROUBLESHOOTING
================================================================================

ISSUE: Still not redirecting to dashboard
SOLUTION:
  - Check if dashboard is running on port 8502
  - Check browser console for JavaScript errors
  - Try the fallback link (should be shown below the redirect message)
  - Make sure localhost:8502 is accessible from your browser

ISSUE: Dashboard loads but Extraction tab not selected
SOLUTION:
  - Check if case_id is in the URL: http://localhost:8502?case_id=CASE_001&auto_extract=true
  - If not, the redirect didn't work properly
  - Check consent portal logs for errors

ISSUE: Case ID not loading in dashboard
SOLUTION:
  - Make sure the case exists in the dashboard
  - Check if case_id in URL matches an existing case
  - Try creating the case manually first, then test approval

ISSUE: Auto-extract message not showing
SOLUTION:
  - Check if auto_extract=true is in the URL
  - If not, the consent portal didn't pass it correctly
  - Check consent portal code (modules/consent_portal.py line 834)

IMPORTANT NOTES
================================================================================

1. PORT CONFIGURATION
   - Consent portal runs on port 8501 (default Streamlit)
   - Dashboard runs on port 8502 (configured in consent portal)
   - Make sure both ports are available

2. URL PARAMETERS
   - case_id: The case ID to load in dashboard
   - auto_extract: Set to "true" to trigger auto-extraction

3. SESSION STATE
   - The session_state is used to persist the auto_extract flag
   - It's cleared after the message is shown
   - This prevents repeated auto-extract on page refresh

4. MOBILE DETECTION
   - Consent portal detects if user is on mobile
   - On mobile, redirect is skipped (user sees message instead)
   - On desktop, redirect happens automatically
