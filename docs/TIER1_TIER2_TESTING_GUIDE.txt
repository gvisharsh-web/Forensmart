TIER 1 & TIER 2 TESTING GUIDE - STEP BY STEP
================================================================================

This guide will help you test all 10 fixes that were just implemented.

Total Testing Time: 45 minutes
Difficulty: EASY

================================================================================
BEFORE YOU START
================================================================================

1. Make sure dashboard.py is saved
2. Start the dashboard: streamlit run modules/dashboard.py
3. Wait for it to load (should say "You can now view your Streamlit app")
4. Open browser to http://localhost:8502

================================================================================
TIER 1 TESTING (25 minutes)
================================================================================

TEST #1: CASE EXISTENCE VALIDATION (5 minutes)
─────────────────────────────────────────────────────────────────────────────

Step 1: Test with invalid case ID
  1. Go to URL: http://localhost:8502?case_id=INVALID_CASE_XYZ&auto_extract=true
  2. Expected: See error message "Case 'INVALID_CASE_XYZ' not found in system"
  3. Expected: See info message "Please create the case first or check the case ID"
  4. Result: ✅ PASS or ❌ FAIL

Step 2: Test with valid case ID
  1. Create a case first (go to Case Management tab, create case)
  2. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID
  3. Expected: Dashboard loads normally
  4. Expected: Case is selected in sidebar
  5. Result: ✅ PASS or ❌ FAIL

TEST #2: APPROVAL VERIFICATION (5 minutes)
─────────────────────────────────────────────────────────────────────────────

Step 1: Test with no approval
  1. Create a case (if not already created)
  2. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID&auto_extract=true
  3. Expected: See error "No approval found for this case"
  4. Expected: See info "Please request approval from the nominee first"
  5. Result: ✅ PASS or ❌ FAIL

Step 2: Test with denied approval
  1. Generate approval link for your case
  2. Open approval link in new tab
  3. Click "❌ No, Deny"
  4. Go back to dashboard
  5. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID&auto_extract=true
  6. Expected: See error "Approval was denied for this case"
  7. Result: ✅ PASS or ❌ FAIL

Step 3: Test with approved approval
  1. Generate new approval link for your case
  2. Open approval link in new tab
  3. Click "✅ Yes, Approve"
  4. Should be redirected to dashboard
  5. Expected: Extraction tab should be selected
  6. Expected: See message "Auto-extraction triggered from approval!"
  7. Result: ✅ PASS or ❌ FAIL

TEST #3: PARAMETER SANITIZATION (5 minutes)
─────────────────────────────────────────────────────────────────────────────

Step 1: Test with invalid case ID format
  1. Go to URL: http://localhost:8502?case_id=CASE@001<script>
  2. Expected: See error "Invalid case ID format"
  3. Expected: See info "Case ID can only contain letters, numbers, underscore, and hyphen"
  4. Result: ✅ PASS or ❌ FAIL

Step 2: Test with very long case ID
  1. Go to URL: http://localhost:8502?case_id=VERY_LONG_CASE_ID_THAT_IS_MORE_THAN_100_CHARACTERS_LONG_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
  2. Expected: See error "Case ID is too long (max 100 characters)"
  3. Result: ✅ PASS or ❌ FAIL

Step 3: Test with invalid auto_extract
  1. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID&auto_extract=maybe
  2. Expected: See warning "Invalid auto_extract parameter, ignoring"
  3. Expected: Dashboard loads normally without auto-extract
  4. Result: ✅ PASS or ❌ FAIL

Step 4: Test with invalid extraction type
  1. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID&extraction_type=unknown
  2. Expected: See warning "Unsupported extraction type: unknown, using default"
  3. Expected: Extraction type should be set to 'android'
  4. Result: ✅ PASS or ❌ FAIL

TEST #4: TIMEOUT HANDLING (5 minutes)
─────────────────────────────────────────────────────────────────────────────

Step 1: Test timeout message (simulate slow loading)
  1. This is hard to test without actually having a slow system
  2. If you have a slow system, redirect should take >30 seconds
  3. Expected: See warning "Redirect is taking longer than expected"
  4. Expected: See "🔄 Retry" button
  5. Result: ✅ PASS or ⏭️ SKIP (if system is fast)

Step 2: Test normal redirect (should clear timer)
  1. Go to URL: http://localhost:8502?case_id=YOUR_CASE_ID
  2. Expected: Dashboard loads quickly (<5 seconds)
  3. Expected: No timeout message shown
  4. Result: ✅ PASS or ❌ FAIL

TEST #5: DEVICE VALIDATION (5 minutes)
─────────────────────────────────────────────────────────────────────────────

Step 1: Test with device connected
  1. Make sure you have a device connected via ADB
  2. Go to Extraction tab
  3. Expected: See device status (✅ Device Connected or ❌ Device Offline)
  4. Expected: See battery and storage metrics
  5. Expected: If device connected, extraction should be allowed
  6. Result: ✅ PASS or ❌ FAIL

Step 2: Test with device offline
  1. Disconnect your device
  2. Go to Extraction tab
  3. Expected: See "❌ Device Offline"
  4. Expected: See error "Cannot start extraction: Device is offline"
  5. Expected: Extraction should be blocked
  6. Result: ✅ PASS or ❌ FAIL

================================================================================
TROUBLESHOOTING
================================================================================

If a test fails, check:

1. Dashboard is running
   - Run: streamlit run modules/dashboard.py
   - Check: "You can now view your Streamlit app"

2. Code was saved
   - Check: modules/dashboard.py has all the changes
   - Check: No syntax errors in console

3. Audit directory exists
   - Check: c:\Forensmart\audit\redirects\ exists
   - Create if missing: mkdir audit\redirects

4. Browser cache
   - Clear browser cache (Ctrl+Shift+Delete)
   - Refresh page (Ctrl+F5)

5. Streamlit cache
   - Clear Streamlit cache: streamlit cache clear
   - Restart dashboard

6. Check logs
   - Look at terminal where dashboard is running
   - Check for error messages
   - Check browser console (F12)
