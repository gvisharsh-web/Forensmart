ISSUE: Not redirecting
SOLUTION:
  1. Check if dashboard is running on port 8502
  2. Check browser console for errors (F12)
  3. Check if URL has case_id parameter
  4. Check if URL has auto_extract=true parameter

ISSUE: Redirects but Extraction tab not selected
SOLUTION:
  1. Check if case_id is in URL
  2. Check if auto_extract=true is in URL
