================================================================================
KEY POINTS
================================================================================

1. URL PARAMETERS PASSED BY CONSENT PORTAL:
   ?case_id=CASE_001&auto_extract=true

2. DASHBOARD READS THESE PARAMETERS:
   case_id_param = params.get('case_id')
   auto_extract_param = params.get('auto_extract')

3. DASHBOARD SETS SESSION STATE:
   st.session_state['case_id'] = case_id_param
   st.session_state['auto_extract_triggered'] = True
   st.session_state['nav'] = 'Extraction'

4. DASHBOARD RENDERS WITH EXTRACTION TAB SELECTED:
   Shows message: "🔄 Auto-extraction triggered from approval!"
   Loads the case
   Shows extraction options

5. USER SEES:
   Dashboard with Extraction tab already selected
   Case loaded and ready
   Message confirming auto-extraction was triggered
