ISSUE DATE: 2025-11-19 16:56 UTC+05:30
ISSUE: Consent portal does not save logging every time it opens
STATUS: ANALYZED & DOCUMENTED
SEVERITY: MEDIUM

================================================================================
THE PROBLEM
================================================================================

SYMPTOM:
- Consent portal doesn't save logs
- Every time app opens, logs are lost
- No audit trail for approvals
- No compliance evidence
- Difficult to debug issues

ROOT CAUSE:
1. No persistent logger configuration
2. Streamlit caching prevents logging re-initialization
3. No file handler configured
4. No audit trail implementation
5. Logging created on-the-fly without persistence

IMPACT:
- Loss of approval history
- No audit trail for compliance
- Difficulty debugging
- No tracking of nominee interactions
- Missing timestamps for decisions

================================================================================
PROPOSED SOLUTION
================================================================================

APPROACH: Implement persistent logging with 3 new modules

MODULE 1: consent_portal_logger.py
  - Persistent file logging
  - Rotating file handlers
  - Structured log format
  - Daily log files

MODULE 2: consent_audit_trail.py
  - Structured JSON audit trail
  - Record all approvals/denials
  - Statistics and filtering
  - Export functionality

MODULE 3: consent_session_logger.py (Optional)
  - Track per-session activity
  - Session event logging
  - Session persistence

ENHANCEMENTS:
1. File logging with rotation
2. Structured JSON audit trail
3. Audit dashboard in sidebar
4. Export audit trail as JSON
5. Statistics and filtering
6. Session tracking
