EXAMPLE: DATABASE SCHEMA
================================================================================

Table: approval_links
  - id (PRIMARY KEY)
  - case_id (VARCHAR)
  - token (VARCHAR UNIQUE)
  - created_at (TIMESTAMP)
  - expires_at (TIMESTAMP)
  - approved (BOOLEAN)
  - approval_time (TIMESTAMP)
  - approval_method (VARCHAR)
  - nominee_name (VARCHAR)
  - nominee_email (VARCHAR)
  - nominee_phone (VARCHAR)

Table: consent_approvals
  - id (PRIMARY KEY)
  - case_id (VARCHAR)
  - approval_link_id (FOREIGN KEY)
  - consent_level (VARCHAR)
  - approved_by (VARCHAR)
  - approval_method (VARCHAR)
  - pin_hash (VARCHAR)
  - approved_at (TIMESTAMP)
  - investigator_notified (BOOLEAN)
  - notified_at (TIMESTAMP)

Table: approval_history
  - id (PRIMARY KEY)
  - case_id (VARCHAR)
  - event (VARCHAR)
  - actor (VARCHAR)
  - actor_role (VARCHAR)
  - timestamp (TIMESTAMP)
  - details (JSON)
